01 · ТЕОРИЯ

Бірөлшемді массив (Python тізімдері)

Тізімнен массивке

Сыныптағы оқушылардың ұпайларын бір қатарға орналастырайық. Әр ұпай — элемент, ал оның орны — индекс. Бірөлшемді массивте элементті табу үшін бір индекс жеткілікті: a[i].

a = [7, -1, 2, 3, 42, 3, 6, 8]

Индекстер 0-ден басталады. a[0] = 7, a[4] = 42. Элемент саны — len(a) = 8, соңғы индекс — 7. a[8] жоқ: оған қатынасқанда IndexError пайда болады.

Мектеп есептерінде бір типтегі мәндер сақталған Python тізімін бірөлшемді массив ретінде қолданамыз. Тізімнің өзі әртүрлі типтегі мәндерді де сақтай алады.

Тізімде әртүрлі типтер бірге сақталады

a = [1, 2, "azamat", 3, 3.14, 4]
print(a)

Natizhe

[1, 2, 'azamat', 3, 3.14, 4]
МәндерТипіМағынасы
1, 2, 3, 4intБүтін сандар
"azamat"strМәтін
3.14floatБөлшек сан

Бір тізімде бүтін сандар, мәтін және бөлшек сан қатар сақталып тұр. Тізімде 6 элемент бар: олардың индекстері 0–5.

Есте сақта: біртипті массивтің элементтері бір типке жатады. Python тізімінде элементтердің типтері әртүрлі бола береді. Мысалы, array("i") бүтін сандарға арналған: оған "azamat" мәтінін немесе 3.14 бөлшек санын қоса алмаймыз.

Сондықтан осы сабақтағы сандық тізімдерді бірөлшемді массив ретінде қолданамыз, бірақ Python-дағы list пен array — екі бөлек тип.

Массив элементтерін қолмен енгізу

n — құрылатын тізімнің элемент саны. Мысалы, n = 5 болса, бес нөл пайда болады.

Анимация үшін: 0–12.

Алдымен n мәнін және n санды жазыңыз. Анимация оларды Python-дағыдай кезекпен оқиды. Мысалы: n = 5, сандар: 7, −1, 2, 3, 42.

a айнымалысы: әлі құрылмады
Natizhe
[0] * n — тізімді қайталау амалы. Python нөлдік тізімді бір өрнекпен құрады. Содан кейін for циклі әр ұяшықтағы нөлді енгізілген санмен алмастырады. Элемент саны өзгермейді.


Әр жолдың мағынасы
  1. from array import array — array класын импорттаймыз.
  2. a = array("i") — әзірге элементі жоқ бүтін сандар массиві. "i" — бүтін сандар, "f" — бөлшек сандар түрінің коды.
  3. n = int(input()) — енгізілген мәтінді бүтін санға айналдырамыз. Элемент саны ретінде теріс емес сан енгіземіз.
  4. a = [0] * n — жаңа Python тізімін құрып, a атауын соған байланыстырамыз. Бұрынғы бос array тізімге айналмайды; айнымалы басқа нысанды көрсетеді.
  5. print(*a) — элементтерді жеке аргументтер ретінде шығарады: жақшасыз, үтірсіз, арасы бос орынмен бөлінеді. Бірінші шығару — нөлдер.
  6. for i in range(n): — i индекстері 0-ден n − 1-ге дейін өтеді.
  7. a[i] = int(input()) — келесі санды оқып, i индексіндегі элементке жазады.
  8. Соңғы print(*a) енгізілген элементтерді шығарады.
Соңғы a типі — list. Сондықтан бұл мысалдың соңғы нәтижесін жасау үшін array импорттау міндетті емес.

1. Элементтерді толтыру
Нөлдерді алмастыруда тізім ұзындығы өзгермейді. append() қолданғанда тізім бастапқыда бос болады да, әр қадамда бір элементке ұзарады.
1.1 · Пернетақтадан енгізу
Оқулық мысалы: N ұяшық ашып, әр нөлді енгізілген санмен алмастырамыз. A = [0] * N жолынан кейін A — list. Жоғарыдағы алғашқы анимация print(*a) пішімін, бұл мысал print(A) пішімін көрсетеді.
N — осы өрістегі сандар саны. Әр сан жеке input() шақыруында оқылады. Бос орынмен бөліңіз.
from array import array
A = array("i")
N = int(input())
A = [0] * N
for i in range(0, N):
    A[i] = int(input())
print(A)

                                            АлгоритмҚалай жұмыс істейді?Салыстыру саны / уақыт өсуі
                                            Көбік – Пузырёк – BubbleКөршілес A[j] және A[j + 1] элементтерін салыстырады. Реті бұзылса, орындарын ауыстырады.Төмендегі нұсқа: n(n − 1)/2 салыстыру; n = 100 болса, 4950. Уақыт: O(n²).
                                            Кірістіру – Вставка – InsertionКелесі элементті сол жақтағы реттелген бөлікке тиісті орнына кірістіреді.Ең нашар жағдайда O(n²); реттелген деректе O(n).
                                            Таңдау – Выбор – SelectionРеттелмеген бөліктегі ең кіші мәнді тауып, сол бөліктің басына ауыстырады.Классикалық нұсқада n(n − 1)/2 салыстыру; O(n²).
                                            Жылдам – Быстрый – QuicksortТірек мәнге қатысты деректерді бөліктерге бөліп, әр бөлікті қайта сұрыптайды.Орташа O(n log n), ең нашар O(n²). Нақты салыстыру саны деректерге және нұсқаға тәуелді.
                                            O(n²) — элемент саны артқанда жұмыс көлемінің шамамен қалай өсетінін білдіреді. Ол n = 100 үшін міндетті түрде 10 000 салыстыру орындалады деген сөз емес. Тиімділікті бағалағанда уақыт пен қосымша жадты бірге қарастырамыз.
                                            2. Көбік – Пузырёк – Bubble
                                            Көршілес екі элементті солдан оңға салыстырамыз. Өсу реті үшін сол жақ мән үлкен болса, екеуін ауыстырамыз. Бір толық өтудің соңында қаралған бөліктің ең үлкен элементі оң жақтағы орнына жетеді. Келесі өтуде сол дайын бөлікті қайта тексермейміз.
                                            Бір өту — ішкі циклдің толық орындалуы. Өсу ретіне >, кему ретіне < салыстыруын қолданамыз. Тең элементтерді ауыстырмаймыз. Жасыл бағандар — соңғы орнына жеткен бөлік.
                                            Bubble · әр салыстыруды бақыла
                                            Жұпты сары түспен белгілейміз, орын ауыстырғанда бағандар қозғалады. i, j, салыстыру мен ауыстыру сандары кодпен қатар өзгереді. Бағытты немесе бастапқы сандарды өзгертіп тексер.
